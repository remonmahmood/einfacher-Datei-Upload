Einfacher Datei-Upload (HTML, CSS, JavaScript)

Dieses Projekt ist ein einfacher Datei-Upload, den ich selbst entwickelt habe, um meine Kenntnisse in HTML, CSS und JavaScript zu vertiefen.
Ziel war es, eine benutzerfreundliche Oberfläche zu gestalten, über die Dateien ausgewählt, hochgeladen und wieder gelöscht werden können.

Ziel des Projekts
Mit diesem Projekt wollte ich zeigen, dass ich
- Interaktive Funktionen in JavaScript umsetzen kann, wie das Hochladen und Löschen von Dateien
- Eine übersichtliche und moderne Benutzeroberfläche mit CSS gestalte
- HTML-Strukturen gezielt einsetze, um ein interaktives Webprojekt zu realisieren

Verwendete Technologien
- HTML5 – Grundstruktur der Webseite
- CSS3 – Design und Layout
- JavaScript – Logik für das Hochladen und Verwalten der Dateien

Funktionen
- Auswahl von Dateien über den Datei-Explorer
- Hochladen und Anzeigen ausgewählter Dateien
- Löschen einzelner Dateien aus der Liste
- Modernes und ansprechendes Design

Vorschau
Die Oberfläche besteht aus zwei Bereichen:
1.Auswahl und Hochladen von Dateien
2.Anzeige der hochgeladenen Dateien mit der Möglichkeit, einzelne Dateien wieder zu löschen
